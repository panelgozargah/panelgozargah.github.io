## درباره | About

این ریپو، وبسایت رسمی و معرفی **گذرگاه** است — پنل پروکسی کامل روی Cloudflare Workers با VLESS + Trojan over WebSocket، حسابداری بایت واقعی، پنل دوزبانهٔ فارسی/انگلیسی با RTL کامل و بدون هیچ وابستگی رانتایم.

This repository hosts the official website of **Gozargah** — a complete proxy panel on Cloudflare Workers with VLESS + Trojan over WebSocket, real byte accounting, a bilingual FA/EN panel with full RTL, and zero runtime dependencies.

## مشخصات وبسایت | Website specs

- طراحی اختصاصی با دیزاین‌سیستم **Gozargah Nexus UI** — تم سینمایی تیره روی `#050816` با گرادیان برند Cyan→Blue→Purple→Magenta
- ذرات تعاملی کم‌تراکم، گلس‌مورفیسم، انیمیشن‌های reveal و شمارنده‌های آماری
- دوزبانه: **فارسی (RTL)** پیش‌فرض + **انگلیسی (LTR)** — سوییچ لحظه‌ای
- کاملاً ریسپانسیو و سازگار با `prefers-reduced-motion`
- خروجی استاتیک Next.js — میزبانی روی **GitHub Pages**
